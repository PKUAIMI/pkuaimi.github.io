# 首页轮播图片

将图片直接放在这个文件夹，构建会自动加入中英文首页，不需要编辑图片清单。

- 顺序由文件名决定，建议使用 `01-名称.jpg`、`02-名称.jpg` 等数字前缀。
- 支持 JPG / JPEG、PNG、WebP、GIF、AVIF。HEIC 请先导出为 JPG。
- 新增、删除或重命名文件即可更新轮播；至少保留一张图片。
- 不读取子文件夹、隐藏文件及本说明文件。中文和空格可用，避免 `#`、`?`、`%` 等特殊字符。
- 推荐长边 1600–2400 像素的网页尺寸图片。图片原比例保留，尺寸自动识别。
- 默认图注自动提供中英文。专属图注可选填在 `content/home.json` 的 `heroLabels` 中。

本地运行 `npm run dev` 时会自动刷新。更新线上网站需运行 `npm run verify`，提交并推送源图片与生成文件。

详细说明见仓库中的 `docs/MAINTENANCE.md` 第 6 节。
