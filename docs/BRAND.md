# 北大视觉规范在网站中的应用

依据用户提供的《北京大学视觉形象识别系统》基础系统（`u5de7ad0c17491.pdf`）及 `pku/` 原始校徽素材。这里记录网页中的实施选择，便于后续维护；不替代学校完整规范。

## 颜色与校徽

- A7（第 4 页）单列的 **Web 值为 `#94070A`**，网站统一使用此值作为北大红。该页同时列出的 RGB `139, 0, 18` 与 Web 值并不相同，网页采用其明确标注的 Web 值。
- `public/styles.css` 的 `--red` 是主色；`--red-dark` 是交互与照片衬底用的深色衍生值，并非额外的学校标准色。暖白和灰色负责阅读区域。
- 页头采用 `pku/标志_红色.png`，页脚采用 `pku/标志（反白，在深色背景下使用）.png`，分别原样复制为 `public/assets/brand/pku-emblem-red.png`、`pku-emblem-white.png`。未重绘、裁切或改变原图颜色，也不使用仅供黑白印刷的黑色稿。
- A6（第 3 页）标志直径为 4x，周围留白为 x。CSS 给校徽四周设置直径四分之一的内边距；红色版置于白底，反白版置于北大红底。不要把云纹、文字或线条放进该留白区域。
- 校徽旁边的 AIMI LAB 与机构名称是网站文字，不是重新制作的官方校名组合标志。浏览器图标继续使用实验室自己的标识。

## 字体

手册 A24（第 9 页）推荐方正中文字体；A25（第 10–11 页）推荐 Garamond 与 Arial 系列。网站使用：

- 正文、导航与操作控件：Arial；中文优先方正中等线简体、方正中黑简体，未安装时回退到苹方、微软雅黑等系统字体。
- 首页主标题、栏目标题与内页标题：Garamond；中文优先方正小标宋简体。未安装时分别回退到 Times New Roman、宋体系列。
- 所有字体优先级集中在 `--sans`、`--display`。正式论文标题与引用内容不因字体调整而改写。

这是本机字体优先的方案，不包含商业字体文件，不依赖外部字体 CDN。因此不同访客未必安装推荐字体，实际显示会依照上述回退顺序。若以后需要所有设备严格一致，应在取得相应网页嵌入授权后添加 WOFF2 字体及 `@font-face`，而不是复制系统字体或从手册提取字形。

## 北大华表云纹

`public/assets/brand/pku-huabiao-cloud.svg` 来自 A30（第 14 页）上方的完整云纹。文件直接保留原 PDF 的 13 个贝塞尔矢量路径，仅转换坐标和路径语法，不含 PDF 页面文字或背景。

云纹作为 CSS 遮罩用于首页介绍区、内页标题区和页脚，使用单色、低透明度、局部裁切的方式；A30 明确允许按版式分割处理。它是装饰，不接收点击，也不会进入屏幕阅读器的内容顺序。不要把云纹铺满正文、盖住照片或变形成新的标志。

## 修改与检查

修改 `public/styles.css` 与 `src/templates/layout.mjs`，再运行 `npm run verify` 同步根目录发布文件。原始 `pku/` 文件夹不是发布目录；网站只发布 `public/assets/brand/` 中使用到的素材。

检查中英文首页、People 与 News 页的宽屏和手机布局，确认校徽留白、文本对比度、菜单、语言切换、轮播、图片预览及搜索仍然可用。品牌装饰应服从学术内容的阅读层次。
